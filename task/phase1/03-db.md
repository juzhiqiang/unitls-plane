# 03 - packages/db (Drizzle Schema + Migration)

> 依赖：02-shared-config
> 预估：3h
> 可并行：与 04-validators 同时执行

## 目标

定义完整数据库 Schema，配置 Drizzle ORM 连接 Supabase PostgreSQL，生成初始 migration。

## 步骤

### 3.1 安装依赖

```bash
cd packages/db
bun add drizzle-orm postgres
bun add -d drizzle-kit @types/pg
```

### 3.2 创建 Schema 文件

`packages/db/src/schema.ts`：

```typescript
import { pgTable, uuid, text, timestamp, bigint, jsonb, smallint, boolean } from 'drizzle-orm/pg-core';

export const users = pgTable('users', {
  id: uuid('id').primaryKey().defaultRandom(),
  email: text('email').notNull().unique(),
  name: text('name').notNull(),
  avatarUrl: text('avatar_url'),
  plan: text('plan', { enum: ['free', 'pro'] }).default('free').notNull(),
  createdAt: timestamp('created_at').defaultNow().notNull(),
  updatedAt: timestamp('updated_at').defaultNow().notNull(),
});

export const files = pgTable('files', { ... });  // 按设计文档
export const tasks = pgTable('tasks', { ... });  // 按设计文档
```

### 3.3 创建索引

```typescript
import { index } from 'drizzle-orm/pg-core';

// files 表索引
index('files_user_created_idx').on(files.userId, files.createdAt),
index('files_expires_idx').on(files.expiresAt).where(sql`expires_at IS NOT NULL`),

// tasks 表索引
index('tasks_user_created_idx').on(tasks.userId, tasks.createdAt),
index('tasks_status_idx').on(tasks.status).where(sql`status IN ('pending', 'processing')`),
```

### 3.4 配置 drizzle.config.ts

```typescript
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  schema: './src/schema.ts',
  out: './drizzle',
  dialect: 'postgresql',
  dbCredentials: {
    url: process.env.DATABASE_URL!,
  },
});
```

### 3.5 创建数据库连接工具

`packages/db/src/client.ts`：
- 导出 `db` 实例
- 导出所有 schema 类型

### 3.6 生成 & 执行 Migration

```bash
bunx drizzle-kit generate
bunx drizzle-kit migrate
```

### 3.7 导出 package 入口

`packages/db/src/index.ts`：
- 导出 schema
- 导出 db client
- 导出类型推断 (InferSelectModel, InferInsertModel)
