# 图片压缩默认尺寸与完整对比设计

## 背景

图片压缩页当前默认选择“电脑”尺寸，会在用户未主动选择时把图片限制到 1920 x
1080。图片对比组件固定使用 16:9 容器，并沿用 `react-compare-slider` 的 `cover`
默认值，导致竖图和其他非 16:9 图片在对比时被裁切。

## 目标

- 图片上传后，尺寸选项默认选中“原始尺寸”，压缩时不主动改变图片宽高。
- 对比区域完整展示原图和处理结果，不裁切图片内容。
- 保留现有拖动对比交互，并控制大图在页面中的最大展示高度。

## 方案

### 默认尺寸

将图片压缩页的默认 `sizePreset` 从 `desktop` 改为 `original`。现有 `resolveSize` 已将 `original`
解析为空尺寸配置，因此本地与服务端处理都不会传递缩放限制，无需修改压缩算法。

### 图片对比

对比组件加载原图后读取其自然宽高，以原图宽高比设置对比容器。容器宽度占满可用空间，同时设置响应式最大高度；当图片很高时，容器在最大高度内收缩。原图和结果图都显式使用
`object-fit: contain`，并以居中方式完整显示。

若原图和结果图宽高比不同，两张图片都完整显示，空余区域使用现有中性背景填充。加载占位不再强制 16:9，避免加载完成时保留错误的裁切约束。

## 影响范围

- `apps/web/src/app/[locale]/(app)/image/compress/page.tsx`：默认尺寸状态。
- `apps/web/src/components/tools/image-compare.tsx`：读取原图尺寸并传递宽高比。
- `apps/web/src/components/tools/image-compare-slider.client.tsx`：自适应容器与完整图片适配。
- 共享对比组件的图片转换、水印页面会同步获得完整展示行为。

## 测试

- 回归测试断言压缩页默认配置使用 `original`。
- 组件测试断言对比图片使用 `contain`，容器使用传入的原图宽高比且不再包含固定 16:9 类名。
- 运行 Web 测试、格式检查和 TypeScript/构建相关检查。
- 在桌面与移动视口核对横图、竖图的完整显示和拖动交互。

## 非目标

- 不改变用户主动选择电脑、手机、证件照或自定义尺寸后的处理逻辑。
- 不改变压缩质量、输出格式、下载和服务端任务流程。
- 不修改对比滑块的视觉样式或交互方式。
