# Dashboard 快捷工具网格空单元修复设计

## 背景

`ToolCatalogGrid` 通过父容器的 `bg-border` 和 `gap-px`
形成卡片分隔线。Dashboard 当前有 10 个推荐工具，在桌面三列布局的最后一行只渲染一个链接，剩余两列直接露出父容器背景，形成一块与卡片不一致的浅灰区域。移动端单列和中等屏幕两列不出现该问题。

## 目标

- 保留现有单列、两列和三列布局及 1px 分隔线。
- 未占满的最后一行使用与工具卡片一致的 `bg-card` 背景。
- 填充单元不包含文案、链接、焦点或辅助技术语义。
- 不修改推荐工具数量、顺序、元数据或页面文案。

## 方案

`ToolCatalogGrid` 根据每组工具数量计算两类填充单元：

- 两列布局：当工具数量为奇数时增加一个 `hidden sm:block xl:hidden` 填充单元。
- 三列布局：增加 `(3 - count % 3) % 3` 个 `hidden xl:block` 填充单元。

填充单元统一使用 `aria-hidden="true"`、`min-h-[132px]` 和
`bg-card`，仅覆盖父容器背景，不参与交互。单列布局隐藏所有填充单元；两列布局只显示两列填充；三列布局只显示三列填充。

相比把父容器改为
`bg-card`，该方案不会丢失内部边线；相比动态改变列数，不会改变工具卡片密度和既有版式。

## 验证

- 组件测试先断言 10 个工具会生成 0 个两列填充和 2 个三列填充，且填充单元不可访问、不可点击。
- 再覆盖奇数工具组，确认两列和三列填充数量分别正确。
- 运行 Web 聚焦测试与全量测试。
- 重新生成 Dashboard 桌面与移动端截图，确认桌面空区恢复为卡片背景，移动端没有新增空白条目或横向溢出。
